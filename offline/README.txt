Marmoset / Mouse Atlas — オフライン版 (Windows x64)

1. ZIPを右クリックして「すべて展開」し、書き込み可能なフォルダに保存します。
2. 展開先の START_ATLAS.cmd をダブルクリックします。
3. ブラウザが開き、同梱データが初回のみ復元されます。復元完了まで待ってください。
4. 利用中は起動した黒いウィンドウを開いておき、終了するときは閉じます。

Windows 10/11 x64 と、現在の Edge または Chrome が必要です。
Node.js は同梱されています。別途インストールやインターネット接続は不要です。
アプリは 127.0.0.1 (このPC内) だけで動き、外部から接続できません。
Mac、Linux、Windows ARM はこの起動パッケージの対象外です。

編集内容は、利用しているブラウザのデータ保存領域に保存されます。
別のPCに移すときやバックアップするときは、アプリ内の「アプリ＋全データ」出力を
使い、更新後の完全なZIPを保存してください。元のZIPや展開フォルダには、
編集結果が自動で書き戻されません。ブラウザのデータを消す前に必ず出力してください。
.atlas-port.json は再起動時に同じ保存領域を開くために使います。削除しないでください。
プライベートブラウズで利用すると、閉じたときに編集内容が失われる場合があります。

クラウドとの通信・同期・ログインは無効です。同梱データは出力時点のコピーです。
外部の参考リンクを開く操作にはネット接続が必要です。
このアプリに保存されていなかった元の imzML / ibd は含まれません。
登録済み分子の画素強度、登録画像、ROI、保存済み設定と空フォルダを引き継ぎます。
